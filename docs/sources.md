## Product references

- **Quetta Video Downloader.** The browser extension and Quetta Browser are separate products. The Chrome listing covers formats, free use, and YouTube restrictions. The product guide describes the download workflow and settings. The published 3.13.0 Chrome and Firefox packages also expose an in-panel video preview. [Chrome Web Store](https://chromewebstore.google.com/detail/quetta-video-downloader/cblecgnkfldiipmmfpiolmfhfphhfngo) · [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/quetta-video-downloader/) · [Desktop extension](https://www.quetta.net/products/pcextension) · [Quetta Browser for macOS](https://www.quetta.net/products/macos)
- **Video Download Helper.** Platform availability, format support, and free and paid features. [Publisher](https://downloadhelper.net/) · [Chrome Web Store](https://chromewebstore.google.com/detail/video-download-helper/lmjnegcaeklhafolokijcfjliaokphfk) · [Premium plans](https://downloadhelper.net/premium)
- **MAX Video Downloader.** Pricing, browser support, media-based thumbnails, and architecture. [Chrome Web Store](https://chromewebstore.google.com/detail/max-video-downloader-%E2%80%93-do/kjinbaahkmjgkkedfdgpkkelehofieke) · [Publisher](https://maxvideodownloader.pro/) · [Architecture](https://maxvideodownloader.pro/architecture)
- **Video Downloader Professional.** The review uses the Chrome version published by Link64 GmbH. [Chrome Web Store](https://chromewebstore.google.com/detail/video-downloader-professi/elicpjhcidhpjomhibiffojpinpmmpil)
- **FetchV.** Formats, streaming and preview features, and platform limits. [Publisher](https://fetchv.net/) · [Chrome Web Store](https://chromewebstore.google.com/detail/fetchv-video-downloader-f/nfmmmhanepmpifddlkkmihkalkoekpfd)
- **猫抓 / Cat Catch.** Source, installation, preview, and parsing documentation. [GitHub](https://github.com/xifangczy/cat-catch) · [Chrome Web Store](https://chromewebstore.google.com/detail/cat-catch/jfedfbgedapdagkghmgibemcoggfppbb) · [Installation](https://cat-catch.94cat.com/docs/install) · [Preview and filtering](https://cat-catch.94cat.com/docs/preview) · [HLS parser](https://cat-catch.94cat.com/docs/m3u8parse) · [DASH parser](https://cat-catch.94cat.com/docs/mpdparse)
